# SecureDNS

Бесплатное приложение для шифрованного DNS на Windows 10 / 11 и Linux.
Лицензия MIT — используйте, копируйте, дорабатывайте свободно.

## Что делает

- Поднимает локальный DNS-прокси на `127.0.0.1:53` (и опционально на `::1:53` при блокировке IPv6/QUIC).
- Все DNS-запросы системы пересылает на **ваши** серверы по шифрованному
  каналу: **DoT** (порт `853` — рекомендуется в РФ), **чистый DoH по URL**
  (как в Chrome — только `https://...` без ручного ввода IP, с авто-резолвом в фоне
  в обход `127.0.0.1`) или **DoH по своим IP** (`:443` / `:8443`).
- Держит встроенный **TTL-кэш DNS** с режимом **Serve-Stale** (мгновенные
  повторные ответы + защита от кратковременных потерь пакетов) и пул постоянных
  соединений (HTTP/1.1 Keep-Alive для DoH, до 4 параллельных сокетов для DoT).
- Умеет дробить первый пакет TLS `ClientHello` по 3 байта (`TCP_NODELAY`) для
  обхода ТСПУ на порту `:443` и проверять провайдера кнопкой **«Тест портов»**
  (`DoT :853`, `TLS/DoH :443` цельный/резка 3B, `TLS/DoH :8443`).
- Опция **«Блокировать IPv6 и QUIC»** отсекает `AAAA`, `SVCB` и `HTTPS` запросы,
  а при желании можно включить временный блок `UDP:443` в Windows Firewall и
  проверить/отключить встроенный DoH в Chrome/Edge/Yandex Browser.
- Опция **«Раздельный DNS»** с редактируемым списком доменов (включая пресет
  Gemini, ChatGPT, Claude, Grok, Perplexity, Cursor, Copilot) и авто-подхватом
  `CNAME`-цепочек: ИИ-трафик идёт через SmartDNS, всё остальное — напрямую через
  DNS провайдера.
- Импорт и экспорт настроек в один клик строкой `securedns://v1/...`, автозапуск
  через Планировщик Windows (без окна UAC) и сворачивание в системный трей.
- Системе назначает DNS `127.0.0.1`:
  - **Windows** — через `Set-DnsClientServerAddress`;
  - **Linux** — через systemd-resolved (`resolvectl`), NetworkManager (`nmcli`)
    или прямую правку `/etc/resolv.conf` (что найдётся в системе).
- Провайдер сети видит только зашифрованный TLS-трафик — содержимое
  DNS-запросов прочитать нельзя.
- Ведёт постоянный журнал событий (`securedns.log`) и по кнопке
  **«Сохранить лог (.txt)»** (или через пункт 5 в CLI) выгружает полный
  диагностический отчёт `.txt` (настройки, DNS адаптеров, слушателей
  порта 53, последние DNS-запросы и историю лога).

Работает с **любыми** серверами — просто впишите IP через запятую.
Никаких предустановленных провайдеров: всё настраивается вручную.

## Как пользоваться

### Windows

1. Запустите `SecureDNS.exe` (Windows спросит права администратора — они нужны
   для смены системного DNS).
2. Впишите IP своих DNS-серверов через запятую.
3. Выберите протокол: DoT (порт 853) или DoH (укажите URL шаблона; IP серверов
   из первого поля используются для прямого подключения к DoH без DNS-резолва
   с перебором при сбое).
4. Для своих серверов по IP оставьте галочку «Проверять TLS-сертификат»
   выключенной. Если хотите строгую проверку в режиме DoT — впишите
   «Домен сертификата» (сертификат выпущен на домен, а не на IP).
5. Нажмите **«Включить шифрованный DNS»** — приложение сначала проверит,
   что сервер отвечает, и только потом применит настройки.
6. Кнопка **«Проверить»** — тестовый запрос через шифрованный канал.
7. Кнопка **«Отключить»** — останавливает прокси и возвращает прежние DNS.

### Linux

Файл `SecureDNS.exe` — это Windows-бинарник, на Linux он не нужен.
Запускается исходник `main.py` (Python 3.10+).

Самый простой путь — готовый лаунчер (сам проверит зависимости и поднимет
права):

```
chmod +x securedns.sh
./securedns.sh
```

**Если окно не открывается** (Wayland-сессия: `couldn't connect to display`) —
есть полноценный терминальный режим, работает везде:

```
./securedns.sh --cli
```

Если вдруг вручную — зависимости и запуск:

```
# Debian/Ubuntu:  sudo apt install python3-tk
# Fedora:         sudo dnf install python3-tkinter
# Arch:           sudo pacman -S tk

xhost +SI:localuser:root   # разрешить root доступ к экрану (Wayland/X11)
sudo -E python3 main.py
```

Смена DNS работает через `resolvectl` (systemd-resolved), `nmcli`
(NetworkManager) или правку `/etc/resolv.conf` — выбирается автоматически,
на Ubuntu/Fedora ничего настраивать не надо.

Дальше всё то же самое: впишите свои серверы, выберите DoT или DoH, включите.

Сборка portable-бинарника под Linux:

```
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name SecureDNS main.py
# бинарник в dist/SecureDNS, запуск: sudo ./dist/SecureDNS
```

## Автообновление

Приложение само проверяет новые версии на GitHub при запуске.
Если вышла новая — в GUI появится кнопка «⬆ Обновить», в CLI — предложение
обновиться. Windows-версия (exe) обновляется и перезапускается сама,
версия из исходников подменяет `main.py` (старый сохраняется как `.bak`).

## Откат настроек

Приложение спроектировано так, чтобы после отключения обычный интернет
работал без проблем:

- Перед сменой DNS сохраняется резервная копия
  (`%ProgramData%\SecureDNS\backup.json` на Windows, `/etc/securedns/backup.json`
  на Linux; для режима resolv.conf — копия `/etc/resolv.conf.securedns.bak`).
- При отключении восстанавливаются сохранённые DNS (или DHCP, если их не было),
  результат проверяется повторным чтением настроек, кэш DNS очищается.
- Если программу закрыли/убили или выключили компьютер с активной защитой,
  при следующем запуске она сама обнаружит «зависший» DNS `127.0.0.1`
  и автоматически вернёт настройки.

## Важно

- Пока шифрование включено, программа должна быть запущена — DNS идёт через неё.
  При закрытии окна приложение предложит вернуть настройки.

## Сборка из исходников

```
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --uac-admin --name SecureDNS --icon icon.ico --add-data "icon.ico;." main.py
```

Готовый exe появится в `dist\SecureDNS.exe`. Зависимостей, кроме стандартной
библиотеки Python 3.10+, нет.
